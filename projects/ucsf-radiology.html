Project 03 · Machine learning

Machine learning for MRI image quality and liver segmentation

Building deep-learning pipelines for MRI assessment, and studying where the models fail.

Role
Machine Learning Intern, Data Analytics
Organization
UCSF Radiology Department
Timeline
May 2026 – Present
Focus
Machine learning

Context

This is ongoing work in the radiology department, using machine learning to support consistent MRI assessment.

What I did

  1. Built a deep-learning pipeline on prostate MRI scans to classify diagnostic image quality.
  2. Trained and evaluated a liver segmentation model, using Dice scores to measure performance across patient data.
  3. Analyzed failure cases and performance distributions to find model limitations and set priorities for the next iteration.

Results

Image-quality classification pipeline built
Liver segmentation model trained and evaluated with Dice scores
Ongoing: failure analysis is guiding next model iterations

Skills used

  • Deep learning
  • Model evaluation
  • Error analysis

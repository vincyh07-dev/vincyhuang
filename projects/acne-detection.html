Acne detection across image datasets

I compared two object detectors on ACNE04, then trained a separate binary acne vs. non-acne patch classifier and tested it on DermNet, a different source of images.

Role
Built and evaluated the pipeline
Data
ACNE04, DermNet
Models
Faster R-CNN, YOLOv8n, ResNet-18
Code
GitHub repository (opens in a new tab)

Problem

The project began with a practical question: could an online image system automatically locate acne regions instead of requiring every spot to be marked by hand? That meant testing which detector could find useful lesion boxes without overwhelming a reviewer with false positives or missing too much.

A second problem was reliability. A model can perform well on the images it learned from and still fail on photos from somewhere else. I compared detector behavior on ACNE04, then tested whether a separate classifier built from ACNE04 patches held up on DermNet images from a different source.

This is an educational computer-vision project, not a clinical diagnostic system.

What I did

I built the pipeline end to end. I trained and evaluated Faster R-CNN and YOLOv8n to find acne lesions in ACNE04 photos, cut lesion and background patches to train a separate binary classifier, and tested that classifier on DermNet.

Two detectors, two kinds of mistakes

Detector results on ACNE04
Detector Precision Recall mAP@0.5
Faster R-CNN 13.9% 62.1% 28.8%
YOLOv8n 42.5% 41.0% 35.4%

For someone reviewing the output, these are different kinds of work. Faster R-CNN found more of the annotated lesions, but at the reported settings most of its boxes were false positives, so a reviewer would spend their time dismissing boxes. YOLOv8n’s boxes were more often correct and its mAP@0.5 was higher, but it missed more lesions, so a reviewer would need to look for what it left out.

What changed and what I learned

Patch classifier evaluation
Patch classifier evaluation Accuracy F1 score AUROC
ACNE04 validation 90.93% — —
DermNet test 63.53% 0.1176 0.5712

The strong ACNE04 validation accuracy told me little about how the classifier would do on another source of images. On DermNet, an F1 of 0.12 and an AUROC of 0.57, barely above chance, showed that it struggled even with augmentation and color normalization in training.

I don’t yet know which difference matters most. Lighting, framing (close lesion patches in training, whole photos in the DermNet test), and how each dataset was collected and labeled are all possibilities to investigate.

Future improvements

Possible next steps:

  • Broader datasets. Train and test on more varied data across skin tones, acne types, lighting, camera quality, framing, and collection sources to improve accuracy and generalization.
  • Error analysis. Sort DermNet mistakes by lighting, framing, and skin condition to see where they cluster.
  • Separate preprocessing comparisons. Test color normalization, test-time cropping, and augmentation one at a time instead of together.
  • Independent evaluation. Hold out a test set from a third source before tuning anything.
Methods and detailed results

Data and annotations

ACNE04 boxes come in YOLO format (normalized center, width, height). For Faster R-CNN I converted them to pixel corner coordinates and shifted class IDs by one to leave room for the background class.

Detectors

  • Faster R-CNN with a ResNet-50 FPN backbone, starting from torchvision’s pretrained weights, with a new box predictor for the acne classes. Trained for 10 epochs on CPU with batch size 1 and SGD (learning rate 0.0005, momentum 0.9).
  • YOLOv8n from Ultralytics’ pretrained yolov8n.pt, trained for 10 epochs at 640-pixel images. The version comes from the training script; an earlier report draft mentioned YOLOv5.
  • A detection counted as correct at IoU ≥ 0.5. Faster R-CNN was scored with my own evaluation script (11-point interpolated AP). YOLOv8n was scored with Ultralytics’ yolo val. Because the two tools differ, treat the comparison as approximate.

Patch classifier

  • Patch sampling: each annotated lesion was cropped with 5 pixels of context and resized to 64×64. For every lesion, one random background patch that overlaps no lesion box was taken from the same photo.
  • Model: ResNet-18 with ImageNet pretrained weights and a two-class output, trained for 20 epochs with Adam and a class-weighted loss.
  • Training used random crops, flips, rotation, blur, and color jitter, plus a gamma adjustment as color normalization.
  • Training accuracy reached 91.03%; the best ACNE04 validation accuracy was 90.93%.
  • On DermNet, images from folders labeled acne counted as positives and all others as negatives. Whole images were resized to 64×64. The classifier labeled 5,589 of 15,557 images as acne.
